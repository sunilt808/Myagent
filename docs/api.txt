# myagent — Free API providers (student plan: no credit card)

> **Last updated:** 2026-09-05 — model ids verified live during the provider-isolation build.
> Run `myagent --list-models` or the `/model` menu to see the current catalog at any time.

Quick list of providers that give REAL free API keys with no credit card.
Work in ~1-2 minutes each. Pick 1-2, create the key, paste into `.env`.

The best free providers myagent already supports out of the box:
`groq/...`, `mistral/...`, `google/...`, `zai/...`, `huggingface/...`.

============================================================
 1. GROQ  (recommended #1)
============================================================
- Website:     https://console.groq.com
- Sign up:     Email only. NO credit card, NO phone.
- Steps:       console.groq.com -> "API Keys" -> "Create API Key" -> copy
- Key env var: GROQ_API_KEY        (looks like: gsk_....)
- In .env:     GROQ_API_KEY=gsk_yourkeyhere
- Free tier:   permanent, free forever, very fast. ~30 req/min,
               up to ~14,400 req/day on small models.
- Best models (verified live Sep 2026):
               groq/openai/gpt-oss-120b    (GPT-class, big)
               groq/openai/gpt-oss-20b     (GPT-class, smaller)
               groq/qwen/qwen3.8-27b       (Qwen 27B)
               groq/qwen/qwen3.6-27b       (Qwen 27B)
- NOTE: older "llama-*" ids (llama-3.3-70b-versatile, etc.) are GONE.
        Use --list-models to see real current ids.

============================================================
 2. MISTRAL  (the "1 billion tokens per month" one)
============================================================
- Website:     https://console.mistral.ai
- Sign up:     Email + PHONE number verification. NO card.
- Steps:       console.mistral.ai -> "API keys" -> "Create new key" -> copy
- Key env var: MISTRAL_API_KEY     (looks like: Xcda....)
- In .env:     MISTRAL_API_KEY=Xcdayourkeyhere
- Free tier:   ~1 BILLION tokens per month, resets monthly.
               That is a lot for a student. NOTE: 2 requests/minute
               limit on the free tier — myagent retries transiently.
- Best models (verified live Sep 2026):
               mistral/codestral-latest     (coding)
               mistral/mistral-small-2603   (general)
               mistral/mistral-small-latest
               mistral/mistral-medium-2604  (larger)
               mistral/ministral-8b-latest
- NOTE: older ids like mistral/free, mistral/open-mistral-nemo,
        mistral/open-mixtral-8x7b, mistral/codestral are no longer
        valid on the API — use the ids above or --list-models.

============================================================
 3. GOOGLE GEMINI  (AI Studio)
============================================================
- Website:     https://aistudio.google.com/apikey
- Sign up:     Google account. NO card.
- Steps:       aistudio.google.com -> "Create API key" -> copy
- Key env var: GEMINI_API_KEY
- In .env:     GEMINI_API_KEY=AIza....
- Free tier:   very generous free tier (Gemini Flash ~1,500 req/day,
               Gemini Pro ~25 req/day). No card.
- Best models: google/gemini-...  (run `myagent --list-models` to see)

============================================================
 4. OPENROUTER  (you may already have this)
============================================================
- Website:     https://openrouter.ai/keys
- Key env var: OPENROUTER_API_KEY
- Free tier:   25+ ":free" models + `openrouter/free` auto-router.
               Free models work even with $0 balance.
- Best models: openrouter/free
               openrouter/google/gemma-4-26b-a4b-it:free
               openrouter/nvidia/nemotron-3-ultra-550b-a55b:free
- WARNING: paid models (gpt-4o etc.) need credit; use :free ones.

============================================================
 HOW TO ADD A KEY (Windows)
============================================================
1. Open the myagent folder (.env file):
       notepad C:\Users\sunil\myagent\.env
2. Add one line per key, e.g.:
       GROQ_API_KEY=gsk_yourkeyhere
       MISTRAL_API_KEY=Xcdayourkeyhere
3. Save, close, and run:
       myagent --providers        (shows which keys are set)
       myagent -m groq/openai/gpt-oss-20b "hi"
4. To make it the default forever, edit ~/.myagent/config.json:
       "model": "groq/openai/gpt-oss-20b"

============================================================
 What about the "GitHub repo with 7.4B tokens" (FreeLLMAPI)?
============================================================
That repo (github.com/tashfeenahmed/freellmapi) is a ROUTER that combines
YOUR OWN free keys from many providers behind one endpoint with automatic
failover. It does NOT create free tokens by itself - you still need to
sign up at each provider and paste your own keys. myagent already does the
same thing for Groq + Mistral directly, no Docker needed. If you later want
34 providers with auto-failover, install that repo yourself; myagent can
point at it as a custom OpenAI-compatible base URL.
